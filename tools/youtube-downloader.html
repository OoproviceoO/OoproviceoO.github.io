YouTube 下載器

把 YouTube 影片存到電腦裡，可以存成影片檔，也可以只留聲音當音樂聽。貼上網址、選格式、按下載，就這樣。

v1.2 Windows 10 / 11　64 位元 免安裝 Python 安裝時需連網
下載安裝檔 約 10 MB　·　裝完會在桌面建立捷徑
下載安裝檔 請用電腦下載

能做什麼

  • 存成影片　畫質可以選最高、1080p、720p、480p。
  • 只存聲音　轉成 MP3，可以放進手機或隨身聽當音樂。
  • 一次抓好幾支　網址一行貼一個，按一次下載就會排隊處理完。
  • 字體可以放大　小、中、大、特大四段，整個畫面一起變大，不是只有文字。
  • 存到哪裡自己決定　選一次就會記住，下次打開還是同一個位置。

怎麼用

  1. 複製 YouTube 網址在瀏覽器上方網址列把整串複製起來。
  2. 貼到第一格打開程式，貼進最上面的空白框。要下載好幾支就一行貼一個。
  3. 選要影片還是聲音MP4 是影片，MP3 是只留聲音。
  4. 按「開始下載」跑完會問你要不要打開資料夾，按「是」就能看到檔案。

更新

不用自己來。打開程式時會自動檢查有沒有新版本，有的話會跳出來問，按「是」就會自己裝好、自己重開，大約十秒。

YouTube 偶爾會改規則導致下載失敗。遇到的話程式會先自己嘗試修復再重試一次；如果還是不行，會跳出視窗請你複製錯誤訊息回報。

安裝時可能遇到的狀況

這個程式沒有買數位簽章憑證，所以 Windows 和瀏覽器會對它比較陌生，跳出提醒是正常的。照下面做就可以。

安裝到最後好像停住不動
這是正常的，不是當機。安裝的最後一步會自動下載影音處理元件，大約 70 MB，依網路速度可能要幾分鐘。請保持網路連線、不要關掉視窗，跑完就會自動完成。
瀏覽器說「無法安全地下載」
點那一列右邊的向上箭頭，選「保留」。
藍色畫面寫「Windows 已保護您的電腦」
點左下角的「其他資訊」，下面會出現「仍要執行」，按下去。
下載完卻找不到檔案
可能被防毒軟體直接刪掉了。打開防毒軟體的「保護紀錄」或「隔離區」，把檔案還原回來。
防毒軟體把檔案隔離
這是誤判，把檔案還原並加入排除清單即可。不放心的話可以先把檔案丟到 VirusTotal 掃描。

使用提醒

請用在自己的影片、開放授權或公眾領域的內容上，或是單純自己留著看的備份。下載有版權的內容再散布出去會有法律問題，YouTube 的服務條款原則上也不允許未經授權的下載。

有問題或發現 bug，歡迎到 GitHub 留言。
