YouTube 自動略過廣告

看 YouTube 時，廣告一出現「略過」就自動幫你按掉。等待略過的那幾秒會自動靜音、快轉。裝好之後就不用管它。

v2.0 電腦版 Chrome／Edge 免費 不收集任何資料
下載壓縮檔 約 7 KB　·　下載後照下面的步驟做
下載壓縮檔 請用電腦下載

安裝步驟（只要做一次，約 3 分鐘）

  1. 1下載壓縮檔

    按上面的「下載壓縮檔」，檔案會存到電腦的「下載」資料夾。

  2. 2解壓縮到「文件」資料夾

    1. 打開「下載」資料夾，找到 YTAutoSkip.zip。
    2. 在它上面按滑鼠右鍵 → 選「解壓縮全部」。
    3. 跳出的視窗按「瀏覽」→ 點左邊的「文件」→ 按「選取資料夾」。
    4. 按「解壓縮」。
    為什麼要放到「文件」？因為之後 Chrome 會一直從這個資料夾讀取。放在「下載」很容易被不小心刪掉，刪掉就會失效。

  3. 3打開「開發人員模式」

    1. 打開 Chrome，在最上面的網址列輸入 chrome://extensions，按 Enter。
    2. 把右上角的「開發人員模式」開關打開。
    用 Edge 的話，網址改成 edge://extensions，「開發人員模式」在左邊。

  4. 4載入擴充功能

    1. 按左上角出現的「載入未封裝項目」。
    2. 跳出的視窗點左邊的「文件」。
    3. 點一下 YTAutoSkip 資料夾（點一下就好，不要點兩下進去）。
    4. 按「選取資料夾」。
    如果出現「無法載入資訊清單」：代表選錯層了。再按一次「載入未封裝項目」，這次點兩下 YTAutoSkip 進去，看裡面如果還有一個 YTAutoSkip，就點那一個再按「選取資料夾」。
完成！ 清單裡出現「YouTube 自動略過廣告」就裝好了。打開 YouTube 看影片，廣告出現「略過」時就會自動被按掉。

能做什麼

  • 自動按「略過」　按鈕一出現就幫你按，跟你自己用滑鼠按一樣。
  • 等待時靜音、快轉　略過按鈕出現前的那幾秒，會自動靜音並用 16 倍速播放。
  • 關掉影片上的橫幅廣告　影片下方跳出來的小廣告也會自動關掉。
  • 可以調整　按瀏覽器右上角的拼圖圖示 → YouTube 自動略過廣告，可以開關功能、調整快轉倍數，還能看已經幫你略過幾次。

常見問題

遇到下面的狀況，照著做就可以。

畫面上方閃了一下黃色的「正在偵錯」提示
這是正常的。這個工具是靠它來模擬真的滑鼠點擊，按完「略過」就會自己消失，不用理它，也不要按「取消」。
Chrome 跳出「停用開發人員模式擴充功能」
按「×」關掉提示就好，不要按停用，按了這個工具就會失效。
突然沒有效了
先確認「文件」裡的 YTAutoSkip 資料夾還在、沒有被移動。還是不行的話，可能是 YouTube 改版了，請看下一題更新。
有新版本要怎麼更新
重新下載壓縮檔，照第 2 步解壓縮到同一個位置，問你要不要取代檔案時選「取代」。接著到 chrome://extensions，在「YouTube 自動略過廣告」上按 ↻ 重新載入。
想暫時關掉
按右上角的拼圖圖示 → YouTube 自動略過廣告，把「啟用」關掉。想恢復再打開。
不想用了，要怎麼移除
到 chrome://extensions，在「YouTube 自動略過廣告」按「移除」，再把「文件」裡的 YTAutoSkip 資料夾刪掉。
安全嗎？
它只在 YouTube 上執行，只會按「略過」和調整廣告的速度音量，不會連到其他網站，也不會收集任何資料。
手機可以用嗎？
不行，只支援電腦版的 Chrome 和 Edge。
